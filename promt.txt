# MASTER WORKFLOW PEMBANGUNAN SISTEM

Gunakan file `modul.txt` sebagai sumber requirement utama proyek.

Jangan mengimplementasikan seluruh aplikasi sekaligus.

Kerjakan aplikasi secara bertahap sesuai urutan fase di bawah. Pada setiap fase:

1. Baca requirement yang relevan dari `modul.txt`.
2. Analisis struktur project yang sudah ada.
3. Jangan menghapus atau merombak fitur yang sudah berfungsi tanpa alasan.
4. Gunakan Laravel best practice.
5. Gunakan migration, model relationship, policy, service/action bila diperlukan.
6. Hindari hardcode role, wilayah, status, dan konfigurasi.
7. Jalankan migration/test/build setelah perubahan.
8. Perbaiki error sebelum melanjutkan.
9. Setelah selesai, tampilkan ringkasan:

   * file dibuat;
   * file diubah;
   * migration dibuat;
   * fitur selesai;
   * testing dilakukan;
   * pekerjaan berikutnya.

Stack utama:

* Laravel 13
* PHP 8.3+
* Filament 5
* Livewire 4
* Tailwind CSS 4
* Alpine.js
* MySQL/MariaDB
* Redis
* Laravel Queue
* Laravel Sanctum untuk API
* MinIO / S3 compatible storage
* Leaflet + OpenStreetMap untuk GIS
* Nginx untuk production

Aplikasi menggunakan modular monolith, bukan microservices.

# PROMPT 04 — AUTHENTICATION, RBAC & MULTI-TENANT SCOPE

Kerjakan Milestone 3.

Implementasikan authentication dan authorization.

Role awal:

1. Superadmin Kabupaten
2. Verifikator Kabupaten
3. Admin Kecamatan
4. Admin Desa/Kelurahan
5. Kontributor jika diperlukan

Setiap user selain administrator Kabupaten terhubung ke `karang_taruna_units`.

Terapkan data scope:

Superadmin Kabupaten:
dapat melihat dan mengelola seluruh data.

Verifikator Kabupaten:
dapat melihat data seluruh wilayah dan melakukan approval sesuai permission.

Admin Kecamatan:
hanya mengelola data unit kecamatannya dan data yang memang diizinkan dari desa di wilayah kecamatannya.

Admin Desa/Kelurahan:
hanya mengelola data unit desanya sendiri.

Jangan hanya menyembunyikan menu di frontend.

Authorization wajib diterapkan server-side menggunakan Policy/Gate/query scope.

Buat dashboard Filament sesuai role.

Tambahkan login, logout, profile user, reset password dan status akun aktif/nonaktif.

Buat test untuk memastikan admin Desa A tidak dapat mengakses data Desa B.
